# 全量资产与覆盖

[逐场资产矩阵](history_event_matrix.csv)列出 76 场、赛季、赛事 ID、项目清单（源可得时）、来源、仓库记录、coverage、rank_scope 及已知缺口。[每场数值名次矩阵](history_verified_matrix.csv)另列独立取得官方源后实际比较的范围。全部 76 场均已入矩阵，不代表全部已官方复核。

- 现有历史记录 1,726 条：个人 1,534，接力 192；接口来源可匹配身份和赛事键 1,458 条，其中 1,398 条的数值总名次一致；官方接口 60 条数值名次和状态为空，不能把仓库 `classified` 视为已验证。
- 对 9 份可获取且哈希匹配的官方成绩册，另外核对 172 个数字名次。2018 和 2022 两个 IOC 地址返回 HTML，而非 PDF，41 条不能据此核验。还有其他 API 分类缺失或身份不能匹配的记录。合计 1,570 个数值名次相同，156 个数值名次未核验；这不是 1,570 条完整成绩已核验。
- 已检查 28 个当前官方赛事目录查询范围，取得分页结果与仓库对应 ID 无差异；这只覆盖所查询范围，不能证明其他年份、类别或赛事不存在遗漏。历史赛季、项目反向覆盖尚未全面核实。
- 公开官方 API 的 651 个响应正文保存在工作区旁的证据目录，清单见 [official_api_manifest.json](official_api_manifest.json)，请求参数见逐行对账。官方来源或解析版本缺少可信修订序列的场合，不把采集时间当成官方修订时间。
- 旧世锦赛全能和超级 3000 米按既定规则排除；接力成员缺失不会阻止团队成绩计入，不凭现役名单补历史阵容。
- 有解析结果和来源链接不等于已保存原始来源。历史资料缺少原文、来源版本、状态或复核证据的部分属于 D09/X01，不能当作通过。
