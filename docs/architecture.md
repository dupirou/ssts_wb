# 网站架构与成绩回顾规划

更新日期：2026-10-27。

本文记录页面职责、成绩回顾与对比的规划，作为后续实现依据。当前分支已接入页面初版；长期规划与本地实现状态分别记录，对比形式可继续调整。

## 全站结构

一级导航保留：首页、赛事、成绩、运动员。增加的页面放在相应栏目内，通过栏目导航和详情链接进入。

成绩档案按“奥运周期 → 赛季 → 赛事”组织。周期包含四个赛季，赛季包含具体赛事，页面入口也体现这一层级。赛季回顾与周期回顾是不同层级的详情页，不作为同级的时间分类；赛季对比和周期对比仍是对比页的两种统计尺度。

| 栏目／页面 | 主要内容 | 页面边界 |
|---|---|---|
| 首页 | 当前或下一场比赛、近期赛程、重要更新与售票入口 | 不放最近赛果和历史成绩列表 |
| 赛事列表 | 按赛季浏览赛历，进入具体赛事 | 负责找比赛，不承载周期统计 |
| 赛事详情 | 赛程、报名、报项、分组及逐轮成绩 | 单场比赛记录的统一详情入口 |
| 成绩首页 | 最近赛果入口、按周期包含赛季的档案索引、对比入口 | 保持为紧凑索引，不堆放全部记录与图表 |
| 赛季回顾 | 一个赛季的各站表现、项目成绩、运动员贡献 | 聚焦一个赛季，可下钻到具体赛事 |
| 周期回顾 | 一个奥运周期的四季走势、项目变化、阵容变化 | 聚焦一个周期，明确资料覆盖范围 |
| 对比 | 两个或三个赛季／周期的并排比较 | 属于成绩栏目；采用独立页面 |
| 运动员目录与详情 | 姓名、协会、已公布赛季排名、个人成绩与跨赛季轨迹 | 不逐人重复报名链接；个人详情逐步接入 |

“本赛季／历史”作为时间条件，不作为两个主要栏目。资料较多时按赛季、周期和具体对象拆成页面，不用大卡片把全部内容塞进同一页，也不为凑齐页面而平均分配内容。

## 页面关系与地址

下表中的新地址是规划，具体参数命名可随实现调整。

| 地址 | 状态／用途 |
|---|---|
| `/` | 已有：首页 |
| `/events/` | 已有：赛事列表 |
| `/events/2026-27/vancouver/` | 已有：赛季与分站详情示例 |
| `/results/` | 本地初版：成绩索引 |
| `/results/events/<competition_id>/` | 本地初版：具体赛事的中国队成绩，支持单项筛选 |
| `/results/cycles/` | 本地初版：周期包含赛季的成绩档案索引 |
| `/results/seasons/<season_id>/` | 本地初版：指定赛季回顾 |
| `/results/cycles/<cycle_id>/` | 本地初版：指定奥运周期回顾 |
| `/results/compare/` | 本地初版：赛季／周期对比，通过查询参数保存选择 |

| `/athletes/<athlete_id>/` | 规划：个人成绩详情，后续接入 |

赛季回顾、周期回顾可以携带当前对象进入对比页；对比页的统计值可以打开构成该统计的成绩，再进入同一套赛事详情。原始记录只保存一份，回顾与对比使用同一数据源派生。

全局导航由 `web/navigation.js` 管理，分站标签只承担分站内部导航职责。保留旧 `/?station=...`、`/history/` 和 `?view=history` 的兼容入口；已有明确赛事、运动员和筛选条件时尽量保留上下文。

## 对比的表现形式

以紧凑的横向并排表格为主。顶部选择对象类型（赛季／奥运周期）、赛事范围与指标；对象选择器放在对应的列表头，第三个对象通过加号按需添加。同一屏中的列对应所选对象，行对应项目。

下面仅展示布局，X 为占位，不代表真实成绩：

| 项目 | 2024/25 | 2025/26 |
|---|---|---|
| 女子 500 米 | 第 X 名 · 运动员 | 第 X 名 · 运动员 |
| 女子 1000 米 | 第 X 名 · 运动员 | 第 X 名 · 运动员 |
| 女子 1500 米 | 第 X 名 · 运动员 | 第 X 名 · 运动员 |
| 女子接力 | 第 X 名 | 第 X 名 |

男子项目与混合接力按相同规则排列。表头固定，项目分组，行距紧凑；手机端固定项目列，成绩列可横向滚动，保持并排关系。

- 切换最佳名次、奖牌、A 组决赛次数等指标时，更新同一张表。比例指标须同时提供分子、分母及统计口径。
- 奥运会、世锦赛、世界杯／世巡赛分别统计，不把不同赛事层级混成一个总数；规则或赛制变化在相关统计旁说明。
- 点击项目行，展开两边构成统计的具体赛事、运动员、名次、成绩状态和 A/B 决赛组别；点击成绩进入赛事详情。
- 周期对比展开后，可按周期第 1～4 赛季对齐。观察项目走势时再展示辅助折线图；只有口径可比且资料充分时连线。
- 每列显示已收录赛事数与缺失范围。未收录显示“未收录”，不能按零计算；部分资料的统计须标明仅覆盖已收录赛事。
- 先完成赛季与周期对比；运动员对比暂不新增页面。运动员姓名仍可作为成绩筛选条件。

最佳名次只能反映最好的一次表现，因此展开区需保留全部已收录成绩，供观察稳定性、参赛阵容与具体比赛差异。周期资料未齐时，不把局部最佳或局部总数写成完整周期结论。

## 数据架构与统计口径

查询和展示采用一致的数据含义；当前比赛同步与历史档案导入可以保持独立流程。

| 数据层 | 职责 |
|---|---|
| 赛事与成绩记录 | 保存具体赛事、项目、运动员／接力队、名次、状态、实际出场与官方来源 |
| 身份与时间索引 | 通过固定运动员 ID、全局赛事 ID、赛季、周期建立关联 |
| 派生统计 | 从成绩记录生成赛季／周期摘要、项目统计与覆盖范围 |
| 页面查询 | 列表、单对象回顾和多对象对比共用统计口径，下钻到构成统计的记录 |

- `competition_id` 包含赛季、赛事类型及必要站次。同城不同站独立，城市不作为跨赛季唯一身份。
- 赛季引用赛事，周期引用赛季。米兰周期对应 2022/23 至 2025/26，当前阿尔卑斯周期对应 2026/27 至 2029/30；周期分组不取代单场记录。
- 运动员使用固定 ID，通过明确别名和可核实的 ISU 身份关联。姓名与代表协会变化不拆断生涯；每次参赛当时的代表协会保留在记录上。
- 中国队范围按参赛当时的 CHN 记录确定。外协会时期的成绩不追溯计入中国队。
- 官方项目最终名次与 A/B 组内名次分开保存。B 组第 1 名不能显示为项目冠军或金牌。
- 接力按队伍计一次成绩；队员的实际出场轮次单独保存，报名名单不等于决赛阵容。
- 赛前报名、实际出赛、DNS、DNF、PEN、取消赛事及资料缺失分别处理，不相互推断。
- 跨周期不直接比较规则不同阶段的原始积分。逐轮晋级、判罚率及交手统计待对应资料完整后再加入。
- 官方来源、文件指纹与页码保留在数据层，页面通过简洁的成绩册链接追溯，避免重复放置说明性文案。

当前 `/data/results.json` 是浏览用派生索引，不能代替原始档案。后续可按赛季／赛事拆分加载，并增加独立摘要；无需一次替换现有同步脚本和 API。

## 加载与页面实现

继续采用静态页面外壳与按需加载的数据。`tools/build.py` 为公开地址生成可直接打开和刷新的页面；CSS、脚本、数据与 SW 使用根路径，共用一套基础外壳。

首页只加载近期信息；赛事栏目按赛季加载赛历；成绩首页读取摘要索引；具体回顾与对比按所选对象加载所需数据；运动员目录在进入时加载。统计定义应集中维护，不在不同页面各写一套算法。

页面文案以名称、数值、筛选和必要状态为主。减少口号、功能解释和重复来源说明；覆盖不足、名次口径等会改变理解的信息仍需就近显示。

## 数据与实现状态

已实现四栏目导航，成绩拆为总览、赛事成绩、成绩档案、对比。档案按“奥运周期 → 赛季 → 赛事”进入；当前为阿尔卑斯周期。手机使用紧凑的层级行和表格，对象选择置于对比表头，两列同屏，第三列可横向滚动。

历史目录 76 场均已建档，其中 74 场有中国队成绩，共 1,726 条纳入统计的成绩、82 位运动员，覆盖 2014/15—2025/26。23 场成绩完整（含两场无中国队记录），53 场尚需核对最终名次；没有整项缺失或待导入赛事。完整度独立于接力阵容，页面分别显示项目缺项、分类与决赛冲突、最终分类缺失。详细范围及来源见 [history.md](history.md)。

周期／赛季回顾已有赛事数、奖牌、A 决赛、前八、逐季／逐站明细及运动员统计。对比支持两或三个对象，按同类赛事比较最佳名次、奖牌、A 决赛次数／比例、前八；展开后可查看原始成绩，周期按第 1—4 赛季对齐。筛选可通过 URL 恢复。

下一步查找原始成绩册解决剩余最终名次问题，再增加运动员个人详情和逐轮表现。世锦赛全能和个人超级 3000 不纳入统计，接力实际阵容缺失可以跳过。当前部分档案不能用于完整周期的奖牌总量或完整晋级率结论。
