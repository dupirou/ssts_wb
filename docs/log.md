## 2026-10-23 · 温哥华官方首轮分组

**来源核查。** 10-22 晚间已有 Swiss Timing 打印的 C48A《Seeding Analysis》报表在流传，但当时 ISU 官网的 Documents 标签只有 Announcement 与 Entries，`front-api.isu.org` 的轮次接口对九个项目都返回空列表；`shorttrack.swisstiming.com`、`shorttrack.sportresult.com` 已不可用，`live.isuresults.eu` 只有大道速滑。

**临时录入。** 用户提供的三张男子项目截图（均为第 1/2 页）曾手工录入为补充分组（PR #19），注明仅第 1 页。

**官方发布。** 当天 ISU 结果接口发布首轮全部 59 组（含三项接力），自动同步接入后整轮替换截图补充。截图录入的数据、原图、对比工具和测试随后删除。

**预测验证。** 以官方首轮分组核对 10-22 发布的预测（只放有世界排名的已知种子）：

| 项目 | 组数 | 已知种子组号正确 | 各组人数 | 直通名单 |
|---|---:|---:|---|---|
| 女子 500m 初赛 | 7 | 5/5 | 一致 | 一致 |
| 女子 1000m 初赛 | 7 | 7/7 | 一致 | 一致 |
| 女子 1500m 1/4 决赛 | 8 | 27/27 | 一致 | 无直通 |
| 男子 500m 初赛 | 10 | 26/26 | 一致 | 一致 |
| 男子 1000m 初赛 | 10 | 23/23 | 一致 | 一致 |
| 男子 1500m 预赛 | 7 | 23/23 | 一致 | 一致 |

合计 111/111。无世界排名的选手按报名成绩分组（报表中的 Assigned Rank 1001 起），程序未预测其组号。

**页面整理。** 赛程中国队行每组一行、估算时间写“约 …”，删除行内重复的“来源”链接；分组弹窗去掉重复的出发位与“分组”标签；倒计时卡的中国队一行缩短；各项都有官方分组后隐藏“分组预测”标签。文档统一移到 `docs/`。
