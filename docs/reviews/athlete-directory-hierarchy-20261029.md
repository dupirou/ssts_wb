# 2026/27 运动员目录与全站卡片信息层级检查

范围：`web/portal.js`、`web/app.js`、`web/results.js`、`web/results-compare.js`、`web/navigation.js`、`web/ui.js`、`web/index.html`、`web/site.css`，以及各页面实际使用的 `dist/` 入口。重点检查重复静态标题、每条记录的身份标签、筛选排序和移动端换行；不更改比赛分类或官方数据。

## 已整改

- 当前赛季运动员目录只在列表上方显示一次“本赛季世巡赛排名”及官方榜单截至站次，不再为每张有排名的卡片重复创建标题。各卡片保留 `500m / 第 N 名` 等真正不同的数值。
- 赛季头盔号显示为纯数字，排在国家/地区代码之前，不含“头盔号”文字或 `#` 字符；仅通过 `aria-label` 保留屏幕阅读器语义。
- 显示顺序为**有官方号码者按数字从小到大，同号码按姓名、稳定 ID**；没有可核验号码的运动员排在最后，按姓名、ID 排列。国家、性别与姓名筛选后继续沿用这一顺序。
- 仅调整前端呈现及 CSS。保持 `dist/data/athletes.json` 中的官方赛季号码、来源站次和赛季榜单不变；不填造未公布的号码。

## 全站其他同类位置的处理结论

| 位置 | 核对结果 | 本次决定 |
| --- | --- | --- |
| 赛事详情的官方报名卡 | 姓名、国家、性别、项目/替补状态是每人的不同属性；没有每卡重复的“本赛季世巡赛排名”标题 | 保留 |
| 赛事详情的排名行 | “单站排名 / 世巡赛积分 / 世界排名”用于区分**不同排名类型**，不是统一的卡片标题 | 保留，以免混淆排名口径 |
| 赛程分组、成绩展开区 | “来源与规则”、分组编号和官方来源分别对应独立比赛/单项；合并会丢失就近操作与证据归属 | 保留 |
| 成绩档案、赛季/周期回顾 | 页面级标题与单条赛事、项目、运动员数据不同；未发现与目录相同的模板标题重复 | 无需改动 |
| 多对象赛事/赛季对比 | 各对象标题、每列项目数据和指标标签用于区分比较对象 | 保留 |
| 运动员累计判罚 | 汇总标题位于列表公共层级；每人“判罚次数/禁赛距离”是独立信息 | 保留 |
| 全站导航与页眉 | 页面导航、无障碍名称是全站共享入口，不属于数据卡片的静态重复文案 | 无需改动 |

本轮目标是消除**没有信息增量的逐卡标题**；不同参赛者的身份、赛场项目、排名类型、证据链接及必要的无障碍标签不会因为字面相同而被误删。

## 回归验收

新增/更新测试覆盖：头盔号纯数字、号码在国家之前、未知号码排序到最后、按数值排序而非字符串排序、筛选后排序稳定、公共榜单标题仅出现一次、原有成绩与排名数值保持不变。最终 CI 与浏览器/PWA 结果以 PR 最新提交的 GitHub Actions 为准。
