# PR #36 整改验收报告

2026-10-28 最终筛选与异步竞态修复验收见 [pr36-final.md](../pr36-final.md)，下文为上一轮架构整改记录。

## 结果

- Ruff 0.16.9 格式失败已修复，保留独立提交。
- 纯成绩模型统一指标与完整度；构建与浏览器使用同一算法。
- 目录为 134,840 字节，回顾／对比按选中赛季读取摘要，列表／展开区按赛事读取原始明细；页面不再请求全量 results.json。
- 列表默认当前赛季，每页最多 4 场；明确选择全部历史也分页。原始明细按需创建，每列每季每组最多 3 场，可翻组。
- 全站仍为首页／赛事／成绩／运动员，周期 → 赛季 → 赛事；390px 双对象并排，三对象内部滚动，项目与统计首列固定。
- 源模块独立可测，构建直接拼接为 site.js，无前端框架或额外构建依赖。原 app.js/navigation.js/portal.js 资源地址仍输出。
- 逐条比对基线：77 场、1,752 条成绩和 statistics_scope 全部一致。保留 API documents/form/响应指纹、PDF 页码与指纹；不推算缺项。全能／个人超级3000仍排除，接力阵容缺失不影响团队完整度。

## 性能

真实数据、390px、3 次独立浏览器上下文中位数，数值含 calendar.json，不含脚本/CSS。DOM 指 app 内全部节点。测试浏览器 Chromium 134.0.6998.35，本地 HTTP 无压缩、无 4G 模拟；启动时间有少量波动，不将总览与对比的几毫秒差异解释为速度改善。

| 成绩总览 | 1,586,664 → 139,089 | 91.2% | 161 → 148 | 212 → 217 ms |
| 赛事成绩（默认范围） | 1,586,664 → 149,602 | 90.6% | 12,357 → 261 | 1553 → 269 ms |

赛事列表从全历史 1,752 行改为默认当前季 26 行；这是有意改变默认范围。指定历史范围后仍能分页访问全部记录。对比与周期回顾的比较对象和口径不变。完整测量及请求路径见 [performance.json](performance.json)。

## 仍未解决

1. 历史四场仍缺最终分类：2024/25 米兰世巡赛第6站（21条）、2023/24 拉瓦尔四大洲（8条）、2022/23 德累斯顿世界杯第5站（13条）与阿拉木图第4站（13条）。本轮不重新推算，相关统计就近显示缺最终分类／已收录部分。
2. 当前温哥华站已收录26条，但完整 programme／最终分类范围未完成确认，标为 partial；未来阿尔卑斯赛季不当作零或完整周期。
3. 目录未显式记录某赛季某赛事类型的空范围时，完整度保守为未知；不能仅凭其他赛事类型的目录推断该类赛事未举行。
4. 性能数据来自本地 Chromium；原生 Android/iOS 安装体验和公网移动网络耗时仍需设备验收。本地新版浏览器下载源不可用，使用已有可下载 Chromium；CI 使用固定镜像预装的新版 Chrome 另行验证。
