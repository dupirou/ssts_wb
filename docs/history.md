## 数据口径

- 范围为成年中国队，参赛当时的代表协会固定保留为 CHN。外协会的历史成绩不会因运动员后来转为中国籍而计入。
- `rank` 是官方最终分类表的项目总名次，不是预赛、小组、A/B 决赛内的名次。`best_time` 是该项最佳时间，不当作决赛时间。
- `final_group` 根据最终分类表的 FA/FB 实际结果列或接力出场列保存，不按名次范围推断。
- PEN、DNS、DNF 等保留为成绩状态；有官方名次时同时保存。未参赛和取消赛事必须另有官方证据，缺失资料不能解释为未参赛。
- 一支接力队保存一条最终成绩。每个队员保存实际参与的轮次，名单来自成绩册 X 标记；赛事报名不视为上场，替换上场的队员不自动算进决赛阵容。
- 页面只显示“当前筛选”的赛事和成绩数，不将部分档案包装成整个周期的奖牌总数、参赛次数或 A 决赛率。原始积分不用于跨周期比较。

## 文件与身份

`data/history/catalog.json` 登记三个周期、12 个赛季及赛事全局 ID。完整档案存放在 `events/<competition_id>.json`；原城市 ID 与当前 `/api/v1/events` 保持独立。赛事 ID 包含赛季、赛事类型、城市与必要站次，同城两站各自独立。

`athletes.json` 保存固定 `skater-*` ID、显示姓名、性别及明确的官方别名。姓名次序仅用于查找已登记别名，导入器不会自动创建未知人物。以后追加 ISU 身份或改显示姓名，不改变已保存的 ID。接力中只有明确性别或唯一登记匹配才能关联。

每场保存官方成绩册 URL、整份 PDF 的 SHA-256 和物理页数；每条结果保存物理页码。`catalog.json` 的来源与指纹必须和结果文件一致。页面每场只放一个“官方成绩册”链接，直接定位当前结果相关页。测试摘录来自 2026 蒙特利尔世锦赛官方成绩册的最终分类表。

## 导入

下载 catalog 指定的官方 PDF，并核对赛事、日期及版本。PDF 只用于本地核验，不提交整本文件。

```sh
python tools/import_history.py 2025-26-worlds-montreal /path/to/protocol.pdf
python tools/build.py
python -m unittest discover -s tests
node --test tests/*.mjs
```

导入命令需要 Poppler 的 `pdftotext`。来源指纹不匹配、分类表不足九个成年项目、身份未知或接力决赛实际阵容不完整时拒绝导入。仅有世界排名、赛季积分表或小组成绩时不会生成最终名次。扫描版和没有可用 Unicode 的 PDF 需先逐页核验，不能自动改读赛季积分表作为替代。

历史导入不接入十分钟一次的实时同步。后续按 2025/26 → 2024/25 → 2023/24 → 2022/23 补齐米兰周期，再整理北京、平昌周期；每批独立核对和发布。
