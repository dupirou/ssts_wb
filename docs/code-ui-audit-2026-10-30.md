## 复用与回退判断

- 温哥华和蒙特利尔使用相同 `renderStation`、`scheduleView`、报名与排名面板。本次未发现两站各维护一套面板，也未新建分站专用渲染器。
- 成绩页的列表、统计、对比已共用 results model/store，聚合数据与明细按需加载。当前赛程与历史最终成绩的证据、字段和交互目的不同，不宜只因都显示姓名/名次就强行合成一个业务面板。
- 保留官方来源身份/结构校验、请求超时、已有可信赛程和离线缓存。这些路径有明确失败场景；不把“存在 catch”直接视为废弃代码。
- `sync_china` 的旧 HTML 适配器仍有生产调用，并且仅处理主数据源尚未覆盖的轮次。仅凭静态阅读不能证明上游永远不再提供该格式，因此此次没有删除。是否退役需用实际源响应与调用日志确认。
- `web/app.js` 与 `site.css` 仍较大。没有为了拆文件再引入平行实现；本轮先减少确实阻塞页面的请求。进一步按路由拆分脚本/CSS，宜单独评估解析耗时后实施。

## 来源、文字和信息密度

来源链接主要位于整块面板底部，分组弹窗保留一个官方来源，预测规则位于折叠区；未发现运动员卡片逐张重复引用来源。保留“非官方预测”“估算时间”“旧赛程”一类影响用户判断的信息。公共排名说明继续只显示一次。

手机分站首屏仍保留下一场与中国队出场信息，因此完整赛程通常需要向下滚动；此次收紧间距而没有移除这些核心信息。底部导航和筛选控件保持可操作尺寸。运动员页仍一次生成全部 203 人，筛选即时生效；后续若人数/DOM 明显增长，可再测分页或虚拟列表，当前未引入这类复杂度。
