# 前端

`web/index.html` 与 `web/site.css` 提供公共外壳；`web/navigation.js` 管理路由与全站导航，`web/portal.js` 提供首页与运动员目录，成绩列表与共享表格在 `web/results.js`，对比选择与状态在 `web/results-compare.js`，纯模型、数据仓库和共享 DOM 分别在 `results-model.js`、`results-store.js`、`ui.js`，`web/app.js` 提供赛事页与共用显示逻辑。前端采用零依赖原生 JS，不用外部字体、图片或 CDN。`tools/build.py` 复制到 `dist/`，不要直接改 `dist/`。`index.html` 与 `manifest.webmanifest` 中的 `{{SEASON}}`、`{{DESCRIPTION}}` 在构建时按 `data/stations.json` 填入，赛事与运动员页面取赛历赛季，成绩页面取成绩索引的 `current_season`，换赛季不必改前端。

## 页面

- **首页 `/`**：当前／下一场赛事与售票卡；只读取当前关注赛事的赛程。
- **赛事 `/events/`**：完整赛季时间轴、全部分站与世锦赛入口。
- **成绩 `/results/`**：最近赛果、按奥运周期包含赛季的档案索引和对比入口；不堆放全部成绩。
- **赛事成绩 `/results/events/`**：按赛事分组的紧凑成绩表；支持周期、赛季、赛事、单项和运动员筛选。具体赛事地址为 `/results/events/<competition_id>/`。旧历史入口和筛选链接继续兼容。
- **回顾 `/results/seasons/<season_id>/`、`/results/cycles/<cycle_id>/`**：单对象的项目成绩与赛事入口；档案入口按周期分组列出已开始的赛季，周期页下钻到赛季、赛季页下钻到赛事，并显示父级导航；未收录范围留空。
- **对比 `/results/compare/`**：两个或三个赛事／赛季／周期横向并排，按赛事类型切换最佳名次、奖牌和 A 组决赛人或队次。赛事模式每列先选赛季再选具体赛事，可跨赛季；隐藏聚合用的赛事范围。单场成绩页提供“加入对比”。项目行展开贡献成绩，周期展开按四个赛季对齐。对象选择器位于对应列表头，第三项按需添加；手机筛选区一行排列。选择写入 URL；窄屏双对象尽量同屏显示，三个对象时固定项目列、表格内部横向滚动。
- **运动员 `/athletes/`**：从本赛季已公布报名名单生成的去重目录；支持姓名（不依赖名姓顺序）、国家与性别筛选，筛选写入 URL。卡片显示姓名、国家、性别及已公布的本赛季世巡赛单项排名，不重复报名链接。
- **分站页 `/events/<season>/<id>/`**（如 `/events/2026-27/vancouver/`，兼容原 `/?station=<id>` 链接）：标题区与数字条；倒计时卡和中国队下一场；“赛程 / 报名名单 / 分组预测”三个标签（预测只在仍有首轮未出官方分组时出现）。`?day=`、`?view=athletes|predictions` 可直达。
- **赛程**：赛程概览（比赛时段刻度与奖牌赛，默认收起）；吸顶筛选栏（比赛日、筛选面板、北京 / 当地时间）；按比赛日分组的列表。桌面为表格，平板两列卡片，手机单列卡片，打印恢复完整七列表格。
- **已比完的轮次**：自动折成一行（时间、项目、轮次和“成绩 / 分组”入口），不再显示中国队小组的估算时间；手机上 CHN 标签缩成星标，平板上占满整行；打印仍是完整表格。
- **接力队员**：分组弹窗里队名下列出 ISU 公布的上场队员；中国队接力行写出队员姓名。未公布前只显示国家。
- **晋级规则**：轮次名后的小标签（如 `2Q+6q`，悬停显示中文），分组弹窗标题下有完整一行；来自 ISU 每轮公布的规则，决赛没有。
- **分组弹窗**：有官方分组的轮次显示“查看分组 / 查看成绩”，弹窗按组列出出发位、姓名、国家、头盔号；有成绩时显示名次、成绩、晋级与判罚。
- **运动员**：报名名单（默认 CHN，国家与性别筛选，名字后小字写性别与所报单项）和排名。
- **新动态横条**：只显示上次关闭后的新条目，首访显示最近 3 天；涉及中国队为红点，A 组决赛成绩为金点，时间调整为蓝点。成绩通知写中国队的去向：晋级、进复活赛、进B组决赛、未晋级（犯规时注明）；决赛写奖牌或第几名；多人时标题写人数，下一行按去向列名字。

`?now=2026-10-25T01:20:00Z` 可预览比赛进行中的状态（只偏移前端时钟）。

全站导航固定为首页、赛事、成绩、运动员；当前分站属于“赛事”。桌面导航在页眉，960px 以下置于底部并预留安全区。分站切换为第二层，详情标签为第三层。栏目与分站地址由 `navigation.js` 管理；成绩页内的回顾、明细和对比地址由成绩模块生成。新增栏目在 navigation 的 sections 与 resolve 中登记。

## 视觉规则

所有颜色都是 `site.css` 顶部的变量：`:root` 为夜间“极光冰蓝”（CSS 注释中的 Arctic Sky），`:root[data-theme="light"]` 为白蓝浅色。主题默认跟随系统，页眉按钮手动切换并记住；`?theme=` 只影响本次访问。

每种用途一种外观：

| 用途 | 外观 |
|---|---|
| 所在位置（分站导航当前站） | 全页唯一的实心主色块 |
| 视图切换（赛程 / 报名名单 / 分组预测） | 下划线标签 |
| 筛选与设置（日期、北京 / 当地、筛选项） | 分段控件 `--seg-*` |
| 操作 | 主按钮深蓝实心 `--cta-*`；次要按钮主色描边 |
| 小状态标签与计数 | 主色淡底 `--sel-*` |
| 静态信息（“ISU 暂定赛程”、DAY 1） | 无容器，图标 + 文字 |

强调色只有两种：中国队红、A 组决赛 / 奖牌赛金。数字用 DIN Alternate / Bahnschrift（回退系统字体）+ `tabular-nums`。动画限于赛道光点、倒计时、入场淡入；`prefers-reduced-motion` 时全部停止。

## 文案约定

- 不放免责声明、法律提示或解释算法的说明句；“非官方”只在预测面板标一次。
- 多个事实用“ · ”分隔且只在“·”处换行（`phrases()` 或 `.nowrap`），短注释不加句号。
- 时间带时段（凌晨 / 早上 / 上午 / 中午 / 下午 / 晚上）。估算时间写“约 00:02–00:04”，官方时间不加前缀。
- 数据时间写“更新于 / 核对于 + 北京时间”或相对时间；同一处不重复写两种时间。
- 来源链接只放一处：赛程行不放来源，分组弹窗与名单底部各有一个“官方来源”。
- 未知信息只在一处说明，未公布的数据不显示“待更新”。
- 数据未齐、缺最终分类、待补或来源冲突等诊断只保留于数据与内部文档，不在页面增加解释提示；A/B 组名次和空状态继续明确。

## 数据契约

成绩栏目按需加载 `results-page.js`，与 `/data/results/index.json` 并行请求，不依赖赛历。目录省略 programme 和内部诊断，仅在完整明细中保留。成绩总览读取轻量目录，回顾与对比按所选赛季读取摘要，列表和原始成绩展开时按赛事读取明细。完整契约见 [results-contract.md](results-contract.md)。原 `/data/results.json` 继续保留，由 `tools/history_data.py` 合并独立档案与当前已构建的官方成绩快照生成，不改写原始成绩，不增加上游抓取。首页与运动员栏目不预取成绩。历史存储仍为 `/data/history/index.json`，不作为页面分栏。运动员目录 `/data/athletes.json` 由 `tools/site_catalog.py` 构建。

统一索引的 `rank_scope=overall` 表示项目最终名次；当前接力只有决赛组内名次时，`rank_scope=final` 并保留 A/B 组，页面明确显示“A组第 N 名／B组第 N 名”，不把 B 组第 1 名标成金牌。每场只保留一个成绩册链接，接力阵容在行内按需展开。

成绩索引排除全能和个人超级 3000；保留女子 3000 米接力。`coverage_detail` 区分项目缺项、未解决的名次冲突和最终分类缺失，只供内部校验和溯源，不在赛事行增加提示或待核对列表。名次来源不一致时采用当前官网正式最终分类，已采用的差异只保留溯源，不再显示为待核对。接力阵容缺失独立记录，不影响成绩完整度。统计与列表使用同一范围。

页面读取 `data/calendar.json`、`data/<id>.json`（赛程）、`data/updates.json` 和 `/api/v1/events/<id>/<resource>`。

- `calendar.json`：`stations[]`（`id`、`city`、`city_en`、`country`、`date_start`、`date_end`、`timezone`、`venue`、`detail_status`、`ticketing`、`predictions`、`source_url`）与 `championships[]`。`source_url` 是该站自己的 ISU 赛事页（尚未找到时为赛季赛历），未出赛程的分站与世锦赛页链接到它。
- `<id>.json` 的 `entries[]`：`round_key`（稳定）、当地与北京的日期时间、`session`（qualifying / repechage / main）、`gender`、`format`、`distance_m`、`round`、`group`（A / B）、`china`，以及有官方规则时的 `qualification`（`code`、`zh`、`text`）。
- `china.status` 为 `confirmed` 才高亮 CHN；`china.heats[]` 含 `number`、`athletes`、`estimate`（非官方估算区间）。
- `sync.last_successful_schedule_check_utc` 为空表示尚未成功核对，不能伪造时间。

## PWA

`web/manifest.webmanifest`、`web/icons/`、`web/sw.js`：先走网络，失败或 4 秒无响应才用缓存，离线时顶部显示“当前离线”。所有页面地址共用一份页面外壳缓存，公共脚本 site.js 在预缓存内，成绩脚本 results-page.js 只随访问缓存。资源地址使用站点根路径，SW 注册于 `/sw.js`、作用域为 `/`。每个栏目和已知赛事均构建独立 index.html，保证直接打开和刷新深链接可用。带查询参数的接口请求不缓存，缓存只包含固定的一组文件。主屏幕图标的快捷入口由构建生成，指向最后一个比赛日尚未结束的分站（之后是世锦赛），每天两次的构建会把它切到下一站；已安装的应用要等浏览器重新读取清单后才会更新。缓存版本按页面外壳文件计算，发布后旧缓存自动清除。

图标源文件 `web/icons/icon.svg`（发光赛道 + 选手点，边缘渐变到 `#070B12`，与启动屏背景无缝），改完运行 `python3 tools/render_icons.py`。从主屏幕打开时先显示同款深色启动页，选手点逆时针滑行，首屏就绪后至少约 0.7 秒淡出。
